# 🎮 دوز (Doz) — بازی کلاسیک، تجربه‌ای مدرن

一个 **حرفه‌ای** و **کاملاً Vanilla** (بدون فریم‌ورک، بدون ابزار build) بازی دوز (Tic-Tac-Toe)، ساخته‌شده با HTML، CSS و JavaScript خالص.

<p align="center">
  <strong>PWA قابل نصب · ۱۶ دستاورد · ۳ سطح AI · آمار و نمودار · بازپخش بازی · تایمر حرکت · و بسیار بیشتر</strong>
</p>

---

## ✨ ویژگی‌های نسخه ۲.۰

### 🎯 حالت‌های بازی
- **دو نفره محلی**: روی یک دستگاه با دو بازیکن
- **در برابر ربات**: با سه سطح دشواری
  - 🟢 **آسان** — حرکت تصادفی با گاه‌وبیاهوش
  - 🟡 **متوسط** — جست‌وجوی محدود با Minimax و گاهی اشتباه
  - 🔴 **سخت** — Minimax کامل با هرس Alpha-Beta (شکست‌ناپذیر!)

### 🧠 هوش مصنوعی
- پیاده‌سازی **الگوریتم Minimax** با **هرس Alpha-Beta**
- سطح سخت واقعاً شکست‌ناپذیر (تست‌شده با ۲۰۰ بازی تصادفی)
- سطح متوسط با احتمال ۲۵٪ حرکت تصادفی
- سطح آسان برای یادگیری

### 📱 PWA (Progressive Web App)
- **قابل نصب** روی موبایل و دسکتاپ
- **آفلاین** کامل (Service Worker با کش هوشمند)
- **میان‌برهای سریع** (Quick Actions) از خانه موبایل
- آیکون اختصاصی (SVG + PNG)
- manifest.json کامل با RTL و فارسی

### 💾 ذخیره‌سازی و بازیابی
- **ذخیره خودکار** وضعیت بازی (Auto-save)
- **بازیابی** پس از رفرش یا بستن مرورگر
- **صادر/وارد کردن** آمار و تنظیمات (JSON backup)
- ذخیره آخرین تنظیمات بازی برای شروع سریع

### 🏅 دستاوردها (Achievements)
- **۱۶ دستاورد** متنوع در ۵ دسته:
  - مبتدی: اولین بازی، اولین پیروزی، اولین مساوی
  - سری پیروزی: ۳، ۵، ۱۰ برد پشت‌سر‌هم
  - شکست AI: آسان، متوسط، سخت
  - سرعت: پیروزی در کمتر از ۵ حرکت
  - حجم: ۱۰، ۵۰، ۱۰۰ بازی
  - مهارت: ۵ مساوی، شکست‌ناپذیر (۱۰ برد بدون باخت)
  - اجتماعی: ۵ بازی دو نفره
- اعلان **Toast** ویژه هنگام باز شدن
- نوار پیشرفت دستاوردها

### 🎨 شخصی‌سازی
- **آواتار سفارشی** برای هر بازیکن (۳۶ ایموجی)
- ۶ رنگ تم قابل انتخاب
- حالت **روشن/تیره/خودکار** (پیروی از سیستم)
- تم‌ها و رنگ‌ها بلافاصله اعمال می‌شوند

### ⏱ تایمر حرکت (Chess Clock)
- تایمر اختیاری برای هر حرکت (۱۰، ۱۵، ۳۰ ثانیه)
- نمایش **حلقه countdown** بصری
- هشدار صوتی در ۳ ثانیه آخر
- حرکت تصادفی هنگام اتمام زمان

### ⏮ بازپخش بازی (Replay)
- ذخیره خودکار آخرین بازی
- پخش خودکار یا گام‌به‌گام
- نمایش اطلاعات بازی (بازیکن‌ها، نتیجه، تاریخ)
- نوار پیشرفت بازپخش

### 📊 آمار و نمودار
- شمارش کل بازی‌ها، برد، باخت، مساوی
- **نمودار دایره‌ای** توزیع نتایج
- **نمودار میله‌ای** ۳۰ بازی اخیر
- **آمار تفکیکی** برای هر سطح AI (آسان/متوسط/سخت)
- سریع‌ترین پیروزی
- بهترین سری برد
- **جدول برترین‌ها** بر اساس نام

### ♿ دسترس‌پذیری
- **حالت کوررنگی** (Color Blind Mode) با الگوهای بصری
- **کنتراست بالا** (High Contrast)
- پشتیبانی از `prefers-reduced-motion`
- پشتیبانی کامل از صفحه‌کلید

### 🔊 صدا
- افکت‌های صوتی کاملاً **سنتزشده با Web Audio API**
- صدای مهره، پیروزی، باخت، مساوی، دستاورد، تایمر
- کنترل میزان صدا

### 🎓 معرفی اولین‌بار (Onboarding)
- ۴ اسلاید معرفی ویژگی‌ها
- نمایش خودکار برای کاربران جدید

### ⌨️ میان‌برهای صفحه‌کلید
| کلید | عملکرد |
|------|--------|
| `۱` تا `۹` | انتخاب خانه (شبیه کی‌پد عددی) |
| `U` | برگشت آخرین حرکت |
| `R` | شروع دوباره دور |
| `H` | نمایش راهنما حرکت |
| `Esc` | خروج به منوی اصلی |

### 🎮 ویژگی‌های گیم‌پلی
- تنظیم **تعداد برد برای پیروزی نهایی** (۱، ۳، ۵، ۷ دور)
- انتخاب **شروع‌کننده** (X، O، یا تصادفی)
- **برگشت حرکت** (Undo)
- **تاریخچه حرکات** قابل مشاهده
- **نمایش خط برنده** با انیمیشن
- **لرزش صفحه** (haptics) روی موبایل
- **راهنما حرکت** با AI سخت
- **بازی فوری** با تنظیمات قبلی

## 🚀 اجرا

### روش ۱: باز کردن مستقیم
فایل `index.html` را در مرورگر باز کنید.

### روش ۲: با سرور محلی (برای PWA)
```bash
python3 -m http.server 8000
# سپس به http://localhost:8000 بروید
```

### روش ۳: نصب به‌عنوان PWA
1. سایت را در مرورگر باز کنید
2. روی آیکون «نصب» در نوار آدرس کلیک کنید
3. یا از منوی مرورگر «افزودن به صفحه اصلی» را انتخاب کنید

## 📁 ساختار پروژه

```
doz-game/
├── index.html              # ساختار اصلی صفحه
├── manifest.json           # PWA manifest
├── sw.js                   # Service Worker (offline cache)
├── css/
│   ├── themes.css          # متغیرهای CSS برای تم‌ها
│   ├── style.css           # استایل اصلی
│   ├── components.css      # استایل کامپوننت‌های v2
│   ├── animations.css      # تمام keyframeها
│   └── responsive.css      # رسپانسیو
├── js/
│   ├── storage.js          # localStorage (تنظیمات، آمار، دستاوردها، آواتارها، state)
│   ├── audio.js            # افکت‌های صوتی با Web Audio API
│   ├── game.js             # منطق خالص بازی (بدون DOM)
│   ├── ai.js               # هوش مصنوعی با Minimax
│   ├── achievements.js     # سیستم دستاوردها
│   ├── timer.js            # تایمر حرکت
│   ├── replay.js           # بازپخش بازی
│   ├── chart.js            # نمودار Canvas
│   ├── ui.js               # رابط کاربری و DOM
│   └── app.js              # کنترلر اصلی
├── assets/
│   ├── icon.svg            # آیکون SVG
│   ├── icon-192.png        # آیکون ۱۹۲px
│   └── icon-512.png        # آیکون ۵۱۲px
└── README.md
```

## 🏗️ معماری

پروژه با الگوی **Module Pattern** طراحی شده:

| ماژول | مسئولیت | وابستگی به DOM |
|-------|---------|----------------|
| `Game` | منطق خالص بازی | ❌ |
| `AI` | الگوریتم Minimax | ❌ |
| `Storage` | ذخیره‌سازی همه‌چیز | ❌ |
| `Audio` | سنتز افکت‌های صوتی | ❌ |
| `Achievements` | سیستم دستاوردها | ❌ |
| `MoveTimer` | تایمر حرکت | ❌ |
| `Replay` | بازپخش بازی | ❌ |
| `Chart` | نمودار Canvas | ✅ |
| `UI` | رندر DOM و تعامل | ✅ |
| `App` | کنترلر اصلی | ✅ |
