# 🎮 دوز (Doz) — بازی کلاسیک، تجربه‌ای مدرن

یک بازی **دوز (Tic-Tac-Toe)** حرفه‌ای و کاملاً **Vanilla** (بدون فریم‌ورک، بدون ابزار build)، ساخته‌شده با HTML، CSS و JavaScript خالص.

## ✨ ویژگی‌ها

### 🎯 حالت‌های بازی
- **دو نفره محلی**: روی یک دستگاه با دو بازیکن
- **در برابر ربات**: با سه سطح دشواری
  - 🟢 **آسان** — حرکت تصادفی با گاه‌وبیاهوش
  - 🟡 **متوسط** — جست‌وجوی محدود با Minimax و گاهی اشتباه
  - 🔴 **سخت** — Minimax کامل با هرس Alpha-Beta (شکست‌ناپذیر!)
- **تورنمنت** (به‌زودی)

### 🧠 هوش مصنوعی
- پیاده‌سازی **الگوریتم Minimax** با **هرس Alpha-Beta** برای کارایی بالا
- سطح سخت واقعاً شکست‌ناپذیر است: یا می‌برد یا مساوی می‌کند، هرگز نمی‌بازد
- سطح متوسط با احتمال ۲۵٪ حرکت تصادفی می‌کند تا بازیکن شانس پیروزی داشته باشد
- سطح آسان برای یادگیری و تمرین مناسب است

### 🎨 رابط کاربری
- طراحی مدرن با **گرادیان و glassmorphism**
- پشتیبانی کامل از **RTL** و فونت فارسی **Vazirmatn**
- ۶ رنگ تم قابل انتخاب
- حالت **روشن/تیره/خودکار** (پیروی از سیستم)
- انیمیشن‌های روان با احترام به `prefers-reduced-motion`
- کاملاً **ریسپانسیو** (موبایل، تبلت، دسکتاپ، لنداسکیپ)

### 🔊 صدا
- افکت‌های صوتی کاملاً **سنتزشده با Web Audio API** (بدون فایل صوتی خارجی)
- صدای قرار گرفتن مهره، پیروزی، باخت، مساوی، کلیک
- کنترل میزان صدا

### 📊 آمار و ذخیره‌سازی
- شمارش کل بازی‌ها، برد، باخت، مساوی
- درصد برد و بهترین سری برد
- **جدول برترین‌ها** بر اساس نام بازیکن
- ذخیره‌سازی با `localStorage`

### ⌨️ میان‌برهای صفحه‌کلید
| کلید | عملکرد |
|------|--------|
| `۱` تا `۹` | انتخاب خانه (شبیه کی‌پد عددی) |
| `U` | برگشت آخرین حرکت |
| `R` | شروع دوباره دور |
| `H` | نمایش راهنما حرکت |
| `Esc` | خروج به منوی اصلی |

### 🎮 ویژگی‌های گیم‌پلی
- تنظیم **تعداد برد برای پیروزی نهایی** (۱، ۳، ۵، ۷ دور)
- انتخاب **شروع‌کننده** (X، O، یا تصادفی)
- **برگشت حرکت** (Undo) — در حالت AI هر دو حرکت برگشت می‌خورد
- **تاریخچه حرکات** قابل مشاهده
- **نمایش خط برنده** با انیمیشن
- **لرزش صفحه** (haptics) روی موبایل
- **راهنما حرکت** (با AI سخت) برای یادگیری
- جشن پیروزی با **کانفتی** 🎉

## 🚀 اجرا

### روش ۱: باز کردن مستقیم
کافیست فایل `index.html` را در مرورگر باز کنید. تمام!

### روش ۲: با سرور محلی (پیشنهادی)
```bash
# با Python
python3 -m http.server 8000

# با Node.js
npx serve .

# با PHP
php -S localhost:8000
```
سپس به `http://localhost:8000` بروید.

## 🏗️ معماری

پروژه با الگوی **Module Pattern** طراحی شده تا کاملاً جداسازی شده باشد:

| ماژول | مسئولیت | وابستگی به DOM |
|-------|---------|----------------|
| `Game` | منطق خالص بازی (board state، win detection) | ❌ |
| `AI` | الگوریتم Minimax و انتخاب حرکت | ❌ |
| `Storage` | ذخیره‌سازی تنظیمات و آمار | ❌ |
| `Audio` | سنتز افکت‌های صوتی | ❌ |
| `UI` | رندر DOM و تعامل کاربر | ✅ |
| `App` | کنترلر اصلی، اتصال همه چیز | ✅ |

این جداسازی باعث می‌شود منطق بازی **قابل تست** باشد و بتوان آن را در محیط‌های دیگر (مثلاً Node.js) هم استفاده کرد.

## 🧪 تست الگوریتم AI (اختیاری)

برای اطمینان از شکست‌ناپذیری AI در سطح سخت، می‌توانید در کنسول مرورگر اجرا کنید:

```js
// تست: AI نباید هیچ‌وقت ببازد
let board = Game.emptyBoard();
let moves = 0;
while (!Game.isGameOver(board) && moves < 9) {
    const player = Game.nextPlayer(board);
    const move = player === 'o' 
        ? AI._hardMove(board, 'o') 
        : AI._hardMove(board, 'x');
    board[move] = player;
    moves++;
}
console.log(Game.checkWinner(board)); // باید مساوی باشد
```
